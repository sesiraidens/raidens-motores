## Sobre

Codigos para controle de motores DC, steppers e servos com drivers L298N, L293D e PCA9685.

---

## Modulos

| Modulo | Funcao |
|---|---|
| dc_motor.py | Controle basico de motor DC |
| l298n.py | Driver L298N (2 motores) |
| stepper.py | Motor stepper 28BYJ-48 |
| servo.py | Servo SG90/MG90S |
| pca9685.py | Driver PWM I2C 16 canais |
